# [uNaviDemo](https://docs.unavlab.com/uNaviDemo/)

Интерактивная демонстрация методов гидроакустической навигации:
**TOA**, **TDOA**, **USBL**.



Вид сверху. Буи и приёмник можно таскать мышью. Есть ползунок шума,
регулировка скорости анимации и демо-режим с автоматической сменой сцен.

## Запуск

Открыть `index.html` в браузере. Или поднять статический сервер:

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Методы
- TOA — односторонний, окружности вокруг буёв, R_i = c·Δt_i.
- TDOA — синхронное излучение GIB, гиперболы по разностям ΔR_ij.
- USBL — короткая база, пеленг по разности фаз, Δφ = 2π·d·sinθ/λ.
